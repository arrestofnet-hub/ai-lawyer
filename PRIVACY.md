# Политика конфиденциальности — AI Юрист Казахстан

AI Юрист Казахстан обрабатывает сведения, которые пользователь передаёт для выполнения юридической задачи: описание ситуации, карточку дела, хронологию, сведения о документах и связанные метаданные.

Данные используются для юридического анализа, сохранения контекста дела, сопоставления материалов, построения стратегии и подготовки проектов документов.

Структурированная память дел хранится в Supabase. Серверная часть размещается на Railway. Секреты доступа не хранятся в публичном репозитории и не должны возвращаться пользователю в ответах.

Сервис применяет принцип минимизации данных: не следует сохранять сведения, которые не нужны для юридической задачи. Пользовательские материалы не должны публиковаться открыто.

Пользователь может запросить удаление конкретного сохранённого дела. Удаление выполняется только после явного подтверждения и включает связанную структурированную память этого дела.

На этапе персонального тестирования доступ организован через серверный контур. Перед публичным многопользовательским запуском требуется отдельная пользовательская аутентификация и изоляция данных каждого пользователя.

Версия: 29 сентября 2026.
